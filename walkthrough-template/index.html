Walkthrough template

One design. Every new feature.

The demo walkthrough looks and behaves the same for every feature. To add a new one you fill in a few lines of text. No new design, no new build. Try it: switch features, edit a step on the right, or start a new one.

What is fixed, and what you fill in

Product and design decided the left column once. A feature owner only writes the right column.

Fixed (same everywhere)

  • Amber “Demo walkthrough” strip with Exit, on every screen
  • Spotlight on the element to tap, with a pulse
  • Coach card: step count, title, text, Back
  • Only the spotlit element works; the real button is relabeled “(demo)”
  • “Nothing was changed” end card, Back to Home, Replay

You fill in (per feature)

  • One line for the “What’s new” sheet
  • Steps: which screen, which element, a title, one sentence
  • What did not change (end card, 2–3 lines)
