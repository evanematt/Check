# Lviv Drive — тренажер ПДР України від першої особи

3D-симулятор водіння у Львові (вид із салону, як на референсі): навчальні квести, практичний іспит на 3 маршрутах із голосовим екзаменатором, практичні вправи на автодромі, теоретичний ПДР-тест і технічний тест (огляд авто + контрольні лампи). Гра відстежує порушення в реальному часі, пояснює кожну помилку з посиланням на розділ ПДР і виставляє оцінку.

«4D» — це 3D + час: доба плине (схід/захід сонця для жовтня у Львові), погода змінюється (ясно, хмарно, дощ, туман, сніг) і впливає на видимість, зчеплення шин та вимоги правил (ближнє світло, склоочисники).

## Запуск

```bash
cd lviv-drive
npm install      # лише для тестів (three.js уже лежить у js/vendor)
npm start        # http://localhost:8080
```

ES-модулі не працюють через `file://`, тому потрібен локальний сервер (`npm start` або будь-який статичний сервер). Потрібен браузер із WebGL (Chrome, Edge, Firefox), клавіатура або геймпад.

## Що є в грі

| Режим | Зміст |
|---|---|
| **Навчання** | 8 квестів: підготовка до руху, світлофор, пішохідні переходи, житлова зона й правило «правої руки», знак STOP, сигнали повороту, паркування, нічна поїздка. Маркер і мінікарта ведуть до цілі; за правильні дії — підказки «Правильно». |
| **Практичний іспит** | Маршрути А/Б/В (день · вечір і дощ · ранок і туман). Екзаменатор дає вказівки голосом (Web Speech, uk-UA) і текстом; збій маршруту — помилка та перебудова маршруту. Фініш — зупинка біля правого краю зі стоянковим гальмом. |
| **Практичні вправи** | Автодром: змійка, екстрене гальмування з 50 км/год, паралельне паркування, заїзд у бокс заднім ходом, зупинка біля стоп-лінії. |
| **Теоретичний іспит** | Білет 20 питань / 20 хвилин / ≤ 2 помилки, рівномірно за темами, з картинками знаків і розбором помилок. |
| **Технічний тест** | Огляд авто перед виїздом (випадкові несправності, рішення «можна / не можна експлуатувати» за розділом 31 ПДР) та тест контрольних ламп. |
| **Довідник** | Усі порушення з балами, посиланнями та порадами; каталог знаків. |

**Автомобіль:** двигун (запуск, заглухання), механіка зі зчепленням або автомат P-R-N-D, стоянкове гальмо, ремінь, покажчики з автоскиданням, аварійка, габарити/ближнє/дальнє, задній протитуманний, склоочисники (3 режими), звуковий сигнал, круїз-контроль, обмежувач швидкості, живі дзеркала (заднього виду й бокові), панель приладів (спідометр, тахометр, пальне, температура, одометр, контрольні лампи), огляд головою (мишею, клавіші 1/3/C). Кнопки на HUD дублюють усі функції.

**Світ:** світлофори з українською послідовністю (зелений → миготливий зелений → жовтий → червоний → червоний+жовтий), пішохідні світлофори, зебри, знаки 2.1/2.2/2.3/3.21/3.29/5.31/5.33 тощо, односторонні вулиці, житлова зона з бруківкою, пішохідна площа Ринок із Ратушею, Оперний театр, AI-трафік (автомобілі, тролейбуси), пішоходи.

### Система оцінювання

Старт — 100 балів: незначна помилка −2, середня −5, груба −10, критична −25 і **іспит не складено** (проїзд на червоний, ДТП, наїзд на пішохода, рух назустріч по односторонній, перевищення понад 40 км/год). Іспит складено: ≥ 80 балів, 0 критичних, ≤ 2 грубих. Додатково показується оцінка за 12-бальною шкалою. Вправи — ≥ 70 балів. На головному екрані — «Готовність до іспиту в ТСЦ» за всіма режимами (зберігається в localStorage).

### Керування

`W/S` газ/гальмо · `A/D` кермо · `Shift` зчеплення · `Q/E` передачі · `M` механіка/автомат · `I` двигун · `Space` ручник · `G` ремінь · `Z/X` поворотники · `V` аварійка · `L` світло · `B` дальнє · `F` протитуманний · `J` двірники · `H` сигнал · `Y` обмежувач · `U` круїз · `1/3/C` огляд · `Tab` завдання · `O` мінікарта · `T` повернути на дорогу · `Esc` пауза. Геймпад: стік — кермо, RT/LT — газ/гальмо, LB — зчеплення.

## Дані: що реальне, а що ні

- **«VISE» / Waze.** Застосунку «VISE» знайти не вдалося. Waze не публікує перелік знаків, світлофорів чи переходів: його партнерська програма (Waze for Cities) віддає лише події (ДТП, затори, перекриття) і лише партнерам. Тому з Waze ці дані отримати не можна.
- **Вбудована карта — схематична.** Назви вулиць справжні (Городоцька, просп. Свободи, Личаківська, Вірменська, Руська, пл. Ринок…), але геометрія та розміщення знаків і світлофорів спрощені й не взяті з обстеження.
- **Реальні дані — з OpenStreetMap.** `tools/import-osm.mjs` завантажує центр Львова з Overpass API (геометрія вулиць, назви, смуги, односторонній рух, обмеження швидкості, світлофори, знаки STOP/«Дати дорогу», пішохідні переходи) і записує `data/lviv-osm.json`. Гра автоматично бере цей файл, квести шукають найближчі відповідні об'єкти, а маршрути іспиту генеруються за картою.

  ```bash
  npm run import-osm                                     # центр Львова
  npm run import-osm -- --bbox 49.835,24.015,49.848,24.040
  npm run import-osm -- --in saved-overpass.json         # офлайн
  ```
  Пріоритет на перехрестях без тегів визначається за класом дороги (евристика). Дані © OpenStreetMap contributors, ODbL.

  У середовищі розробки доступ до Overpass був закритий, тому імпорт перевірено лише на синтетичному прикладі (`test/import-osm.test.mjs`), а не на справжньому вивантаженні Львова.

## Правила (стан на 2026 р.)

Посилання — на ПДР України (постанова КМУ №1306), перевірено у жовтні 2026 р.: 50 км/год у населеному пункті, 20 км/год у житловій зоні, 1,6 мм протектора, 10° люфту керма, 0,2 ‰ тощо. Де номер пункту не перевірено, гра посилається на розділ. Штрафи навмисно не показано: суми змінюються, а законопроєкт №15348 (зниження порогу перевищення швидкості до 10 км/год) на момент перевірки не ухвалено. Перед складанням іспиту звіряйтеся з чинним текстом на [zakon.rada.gov.ua](https://zakon.rada.gov.ua/laws/show/1306-2001-п).


## Обмеження

Немає трамваїв і кругового руху (у мережі вони були б звичайними перехрестями). Для повного обгону немає окремої логіки. AI не змінює смуги. Керування розраховане на клавіатуру або геймпад, сенсорного керування немає.
