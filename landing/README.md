# Намалюй мені рись — лендинг

Перший екран благодійного лендингу розмальовки «Намалюй мені рись» (Roboneers × СЕНС).

Нічна сцена з окремих шарів: небо з полярним сяйвом, дальні замети, два передні замети. У ній два інтерактивні об'єкти:

- **Книга-розмальовка (3D)** праворуч стоїть за правим заметом. По гребеню цього замету лежить гірлянда, така сама, як на НРК, і обкладинку вона не перекриває. При наведенні (тапі на телефоні) вона вилітає з-за нього, а поруч відкривається модалка з описом і кнопками «Спробувати» / «Купити».
- **Сніг** постійно падає по всій сцені.
- **НРК з риссю** ліворуч стоїть за лівим заметом. При наведенні (тапі) НРК підстрибує з-за замету. Рись повертає голову за курсором. На НРК висить гірлянда, яка мерехтить і тепло підсвічує все навколо.

Над сценою лежить легке «марево» (дісторшн). Угорі скляний хедер з лого Roboneers × СЕНС.

## Як запустити

Це статичний сайт без збірки, без npm і без фреймворків. Потрібен лише локальний сервер, бо з диска (`file://`) браузер не завантажить 3D-модель і модулі:

```bash
cd namaliuy-meni-rys-landing
python3 -m http.server 8000
```

Відкрий http://localhost:8000.

Бібліотека для 3D (three.js 0.160.0) і шрифти (Google Fonts: Inter, Unbounded) підвантажуються з інтернету. Без мережі не буде книги й шрифтів.

## Як змінити типові речі

### Тексти модалки й посилання

У `index.html` знайди `<aside class="book-card"`:

- **Опис:** `.book-card-text`, зараз там текст-заглушка.
- **Кнопки:** `«Спробувати»` і `«Купити»`, у `href` зараз `#`.
- **Заголовок** — це картинка `assets/book-card-title.svg`. Щоб змінити назву, експортуй новий SVG з Figma з такою самою назвою файлу.

### Хедер

У `index.html` блок `<header class="site-header">`:

- **Пункти меню** («Про проєкт», «Розмальовка», «Як допомогти»): тексти й `href`.
- **Кнопка «Купити»:** `href`.

На екранах до 720 px пункти меню ховаються, лишаються лого й кнопка.

### Композиція (де стоять замети)

Сцена зібрана з шарів так само, як у референсі 2000×1306. Положення шарів задані у `styles.css`, у правилі `.hero`, у відсотках цього кадру:

- `--dl-x`, `--dl-y`, `--dl-w` — лівий замет;
- `--dr-x`, `--dr-y`, `--dr-w` — правий замет.

Дальні замети задані в правилі `.dunes`.

Для вертикальних екранів (телефонів) є окремі значення в `@media (max-aspect-ratio: 4/5)`. Там замети зсунуті до центру, щоб у кадр влазили і НРК, і книга.

### Положення й розмір книги

`book.js`, на початку файлу, `PLACE`:

- `fx`, `fy` — точка всередині **картинки правого замету** (частки її ширини й висоти), де стоїть книга. Книга завжди ховається за тим самим місцем замету.
- `size` — висота книги відносно ширини замету.
- `wide` — для десктопа, `narrow` — для телефона.

Там само:

- `BURY` — наскільки книга закопана.
- `HOP` — наскільки високо вилітає.
- `LEAN` — нахил назад.

### Положення, розмір і підскок НРК

`styles.css`, правило `.hero`:

- `--nrk-dx`, `--nrk-dy` — зсув відносно лівого замету;
- `--nrk-w` — ширина.

НРК завжди рухається разом з лівим заметом. Висота підскоку — `.hero.nrk-up .nrk` (`translateY(-16%)`).

### Гірлянда

- **Кольори лампочок і мерехтіння:** `styles.css`, `.nrk-garland …` і `@keyframes twinkle` / `garland-flicker`.
- **Де проходять дроти:** `nrk.js` → `STRANDS`. Це координати в просторі картинки НРК 1274×1517.
- **Сила теплого світла на НРК і на снігу:** `nrk.js`, функція `paintLight`. Там значення прозорості в `rgba(…)`.

### Гірлянда на правому заметі (біля книги)

`nrk.js`, виклик `buildGarland('driftGarland', …)`: точки, по яких лежить дріт, у координатах картинки замету 1660×580. Останнє число у виклику (`1.4`) — розмір лампочок. Замет на передньому плані, тож лампочки тут приблизно в 3,4 раза більші, ніж на НРК. Тепле світло від неї на книзі — `garlandLight` у `book.js`.

### Тепле світло гірлянд на снігу

`styles.css`, правила `.dunes-light`, `.drift-left-light`, `.drift-right-light`. Це теплі плями на снігу під НРК і книгою. Яскравість задає прозорість у `rgba(…)`, розмір — перші два відсотки в `radial-gradient(…)`.

### Падаючий сніг

`main.js`, блок «Constant snowfall»:

- `LAYERS` — розміри й швидкості для дальнього, середнього й ближнього снігу;
- `seed()` — кількість сніжинок;
- `loop()` — вітер.

### Нічний відтінок НРК, рисі й книги

- **НРК і рись:** `index.html`, фільтр `<filter id="moonlit">`, кольорова матриця.
- **Книга:** у `book.js` (`GRADE.book`) та сама матриця, тільки в шейдері. Тримай їх однаковими, щоб усе виглядало з одного світу.

### Дісторшн

- **Сила:** `index.html` → `<filter id="warp">` → `feDisplacementMap scale="7"`. Більше значення — сильніше марево, `0` вимикає.
- **Швидкість і характер:** `nrk.js`, блок «Heat-haze distortion».

Для людей з увімкненим «зменшити рух» дісторшн і анімації вимкнені автоматично.

## Відомі обмеження

- **Дісторшн навантажує систему:** він перераховується для всього екрана. На слабких ноутбуках і телефонах може підгальмовувати. Якщо так, зменш `scale` або вимкни фільтр на телефонах.
- **Розмір сторінки:** кадри рисі важать 1,6 МБ, і це найважчий файл. Загалом сторінка близько 2,8 МБ.
- **Плейсхолдери:** опис книги, ціна й посилання поки заглушки.
- **Лого:** зроблене з невеликого растрового PNG. Якщо буде SVG, краще замінити.
- **НРК на телефоні:** книга трохи перекриває край НРК, бо екран вузький.
- **Окремий інтерактив рисі:** на телефоні немає курсора, тож рись дивиться туди, куди торкнулись, а без дотиків сама озирається.
- **Лише перший екран:** інших секцій ще немає, хедер не липкий.

## Як перевірити зміни

Скрипт для скриншотів потребує Node.js і Playwright (`npm i -D playwright`, потім `npx playwright install chromium`). Сервер має бути запущений на порту 8000:

```bash
node tools/screenshot.mjs http://localhost:8000 ./shots
```

Скрипт робить скриншоти десктопа й телефона: у спокої, з відкритою модалкою і з курсором у кількох місцях для рисі. Подивись їх перед тим, як віддавати зміни. Підскок НРК перевір вручну, навівши курсор на НРК.
