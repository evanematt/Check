# Левандівка: по той бік району

Кооперативна пригода для **Minecraft Java 1.20.1 (Fabric)**, для 1–3 гравців. Райони Левандівки, таблетка «Хрома»,
яскравий вимір Хромандівка, п'ять босів і двоє котів: Чіназік та Метадонна.

Орієнтовна тривалість першого проходження: 4,5–6 годин (див. «Статус»).

## Встановлення

Стороння залежність **Fabric API не вбудована в `lewandivka-*.jar`**. Її (і решту модів) ставить модпак.

### TLauncher (найпростіше)
1. У TLauncher вибери версію **Fabric 1.20.1** і один раз запусти її (щоб Fabric поставився).
2. Скачай з Releases `Lewandivka-TLauncher-1.0.0.zip`, розпакуй у будь-яку папку і двічі клацни **Install.bat** (він завантажує Fabric API та інші моди з Modrinth).
3. Запусти профіль Fabric 1.20.1. Усі гравці (і сервер) мають мати однаковий набір з нашим модом.

### Modrinth App / Prism Launcher
Імпортуй `Lewandivka-1.0.0.mrpack`. Усі моди підтягнуться автоматично.

### Вручну (розробка)
Потрібні: Fabric Loader ≥ 0.14.21 для 1.20.1, **Fabric API** (окремо), `lewandivka-1.0.0.jar` у `mods`.

### Сервер
Розпакуй `Lewandivka-Server-1.0.0.zip`, запусти `start.sh` або `start.bat` (Java 17+). У пакеті немає клієнтських модів
(Sodium, Iris, Continuity, Visuality, Presence Footsteps, More Culling, Mod Menu, шейдерів).

## Керування
* **V** — ривок (після Гаражного Короля).
* **Стрибок у повітрі** — планер (після Кондуктора).
* **ПКМ по Районному блокнотові** — завдання, підказка, історія.
* **ПКМ по коту** (після Притулку) — меню команд. Будь-хто з гравців командує будь-яким котом.
* `/lewandivka status`, `/lewandivka compass`. Для операторів: `setstage`, `checkpoint`, `reset encounter <назва>`,
  `ability grant|revoke`, `party <0-3>`.

Налаштування: `config/lewandivka.json` (тремтіння екрана, зменшення спалахів, щільність частинок, складність босів, підказки).

## Пресети графіки
| Пресет | Шейдер | Дальність | Примітка |
|---|---|---|---|
| Performance (типовий) | вимкнено | 8–12 чанків | `config/iris.properties` з `enableShaders=false` |
| Cinematic | MakeUp UltraFast | 12–16 чанків | у меню Шейдерів вибери MakeUp-UltraFast |

Шейдери ніколи не обов'язкові; усі підказки зрозумілі без них.

## Вирішення проблем
* Нічого не з'являється в меню → у лівому нижньому куті має бути «Fabric», а не «Forge».
* Вилітає при старті → видали з `mods` усе зайве (старі версії мода, Forge-моди).
* Місто з'являється лише в **новому** світі.
* Статус збірки і перелік модів: `pack_report.txt` у релізі.

## Статус (чесно)
Це проєкт у розробці, а не завершена гра з опису вимог. Зараз реалізовано й збирається:
два виміри (місто в Overworld і Хромандівка), місто на старті, Шлагбаум із прокачкою і квестами, чотири боси
та Колекціонер, коти, кастомні текстури, HUD, блокнот, здібності з клавішами (V, планер), таймер Хроми з боссбаром,
відновлення квестових предметів, адмін-команди, пакування (.mrpack, сервер, TLauncher) і документація.

**Ще не реалізовано** (за планом фаз): окремий вимір `lewandivka:district`, GeckoLib-анімації, фінальний бос у трьох фазах
із зарядом і реле, вежа з талонами, катсцени (трамвай, перехід), постгейм, повний набір досягнень, автоматичні GameTest.
Жодне з цього **не перевірялось запуском у грі**: збірка перевіряє лише компіляцію і юніт-тести.

## Сторонні компоненти
Див. `THIRD_PARTY.md` (генерується збіркою з метаданих Modrinth) і `docs/`.

## Розробка
`./gradlew build` → `build/libs/lewandivka-1.0.0.jar`. Текстури: `python3 tools/gen_textures.py`, `python3 tools/import_refs.py`;
дані: `python3 tools/gen_data.py`; модпак: `python3 tools/build_pack.py <jar> dist`.
