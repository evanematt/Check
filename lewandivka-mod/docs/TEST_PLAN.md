# План тестування

Автоматичні (запускаються в `./gradlew build`):
* `CampaignTest` — порядок етапів, масштабування вікна синхронізації за розміром групи.

Ручні (потрібен запущений Minecraft; цього середовища розробки для них недостатньо):
1. Новий світ → старт у місті, блокнот у інвентарі, HUD зверху-ліворуч.
2. `/lewandivka status`, `/lewandivka setstage CHROMA_READY` → таблетки/етап змінюються.
3. Хрома: один гравець з'їв → боссбар «ХРОМА»; 5 хв без решти → таблетка повертається.
4. Втратити чайник/посилку/компостер (смерть, лава) → за ≤30 с предмет повертається.
5. Після босів: `/lewandivka status` показує здібності; V = ривок; стрибок у повітрі = планер; рестарт сервера не скидає.
6. `/lewandivka party 1|2|3` → вікна синхронізації змінюються; бос-перемикачі проходяться соло.
7. `/lewandivka reset encounter garage` повертає бою чистий стан.
8. Виділений сервер: запуск з `Lewandivka-Server-*.zip` без клієнтських модів, без ClassNotFound.

Відомі незавершені пункти: див. «Статус» у README.
